Quản Lý Tủ Sách Google Drive

Chỉnh sửa, thêm sách mới hoặc xóa sách. Lưu trực tiếp qua GitHub Sync hoặc bấm "Xuất File" để lấy `books.json`.

Quy chuẩn đường link Google Drive:
  • Link đọc file sách: Đặt quyền chia sẻ là "Bất kỳ ai có đường liên kết này đều có thể xem". Dán trực tiếp link chia sẻ dạng https://drive.google.com/file/d/.../view.
  • Link ảnh bìa: Dán link chia sẻ Google Drive, hệ thống tự động chuyển thành link ảnh trực tiếp https://lh3.googleusercontent.com/d/{ID}.
